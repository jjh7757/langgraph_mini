# 서비스별 도메인 구조

각 서비스가 실제로 저장(Repository로 관리)하는 도메인 모델의 필드를 정리한 것.
value object(`TransferCondition`, `TransactionFilter`, `ConditionalTransferQuote`,
`BillPaymentResult`, `BillPaymentAttempt` 등 — 저장소에 저장되지 않고 호출 중에만 쓰는
입출력 객체)는 여기 포함하지 않음. 코드 기준: `src/langgraph_mini/<service>/domain.py`.

## Account 서비스

### 계좌 — accounts

| 필드 | 자료형 | 설명 |
|---|---|---|
| account_id | 문자열 | 계좌 ID |
| owner_id | 문자열 | 계좌 소유자 ID |
| nickname | 문자열 | 계좌 별명 (같은 owner_id 내에서 중복 불가) |
| balance | 정수 | 현재 잔액 (원 단위, float 금지) |

### 거래내역 — transactions

| 필드 | 자료형 | 설명 |
|---|---|---|
| account_id | 문자열 | 이 거래가 속한 계좌 ID |
| transaction_type | 열거형(이체출금·이체입금·카드결제·청구서납부) | 거래 종류 |
| amount | 정수 | 거래 금액 |
| counterpart_id | 문자열 \| None | 이체 상대 계좌 ID (카드결제·청구서납부면 None) |
| card_id | 문자열 \| None | 카드결제일 때 사용한 카드 ID (아니면 None) |
| bill_id | 문자열 \| None | 청구서납부일 때 납부한 청구서 ID (아니면 None) |
| created_at | 일시 | 거래 발생 시각 |

이체 한 건은 계좌별로 갈라서 두 건(TRANSFER_OUT/TRANSFER_IN) 생성됨 — 계좌 단위
거래내역 조회를 가능하게 하기 위함 (account/domain.py의 Transaction docstring 참고).

## Card 서비스

### 카드 — cards

| 필드 | 자료형 | 설명 |
|---|---|---|
| card_id | 문자열 | 카드 ID |
| account_id | 문자열 | 이 카드로 결제 시 출금되는 계좌 ID |
| name | 문자열 | 표시용 카드 이름 (예: "국민 체크카드") |
| kind | 열거형(신용·체크) | 카드 종류 |
| status | 열거형(사용가능·일시잠금·분실정지) | 카드 상태 (기본값: 사용가능) |

### 재발급 신청 — reissue_requests

| 필드 | 자료형 | 설명 |
|---|---|---|
| request_id | 문자열 | 재발급 신청 ID |
| card_id | 문자열 | 재발급 대상 카드 ID (LOST 상태인 카드만 신청 가능) |
| delivery_address | 열거형(집·회사) | 배송지 |
| status | 열거형(접수·제작중·완료·취소) | 처리 상태 (기본값: 접수) |
| created_at | 일시 | 신청 시각 |

## Billing 서비스

### 청구서 — bills

| 필드 | 자료형 | 설명 |
|---|---|---|
| bill_id | 문자열 | 청구서 ID |
| owner_id | 문자열 | 청구 대상(소유자) ID — 특정 계좌에 미리 묶여있지 않음 |
| name | 문자열 | 청구서 이름 (예: "전기요금") |
| amount | 정수 | 청구 금액 |
| due_date | 날짜 | 납부 기한 (지나도 연체료 없이 납부 가능) |
| status | 열거형(미납·납부완료) | 납부 상태 (기본값: 미납) |
